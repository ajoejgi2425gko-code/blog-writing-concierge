ブログ制作コンシェルジュ v3

GitHub Pages: ZIPを解凍し、references フォルダを含め全ファイルをリポジトリ直下にアップロードしてください。

新機能：H2画像制作アシスタント。完成記事のH2を抽出し、16:9・文字なし・1枚ずつの画像生成指示を作成します。
基準画像3枚は references/ に含まれます。生成AIへ画像ファイルは自動送信されません。必要な人物の基準画像を利用者が生成AIへ添付してください。
このPWAは画像そのものを生成しません。文章生成・画像生成とも外部AIサービスで実行します。
既存のブログ作成、リライト、監査、コピー、共有、保存、3つのAIリンクは維持しています。
