ブログ制作コンシェルジュ v5（個人用）

GitHub Pages：このZIPの内容をリポジトリ直下にアップロードしてください。references/の画像も必要です。

記事制作：新規・リライト・診断・部分修正。段階式ワークフロー（診断→改善方針→保持台帳→執筆→監査）を継続。
H2挿絵：各章の画像生成プロンプトを作成。基準画像をAIに別途添付。ファイル名とalt案を依頼。キャプションは原則不要。
一般画像SEO：画像を複数選択して端末内でプレビュー。補足を記入し、画像番号付きの一括AI依頼文を作成。AIには画像ファイルを別途添付する必要があります。画像対応表CSVも保存可能。

注意：本PWAは画像生成や画像解析を直接実行しません。AIサービスへの画像自動送信・WordPressへの自動アップロードは行いません。
画像ファイルの形式変換も実行しません。ファイル名の拡張子は実際の保存形式に合わせてください。
サービスワーカーによる基本画面のオフライン表示に対応。

アイキャッチ画像：記事全体の内容を基に画像生成プロンプトを作成。16:9、文字なし初期設定。基準画像を別途AIに添付。生成後のファイル名・alt・タイトルも提案依頼。
