ブログ制作コンシェルジュ v1

GitHub Pages: ZIPを展開し、すべてのファイルをリポジトリのルートにアップロードしてください。Settings > Pages > Deploy from a branch > main / (root)。

使い方: ブログと作業モードを選択し、原稿を貼り付けるかテキストファイルを読み込み、プロンプト生成→コピー→ChatGPT/Gemini/Copilotへ貼り付け。

注意: AIへの自動送信なし。原稿はブラウザ内で処理し、アプリ側のサーバーへ送信しません。ブラウザのキャッシュにアプリ本体が保存されます。AIサービス側への貼り付け時の情報管理は各サービスの設定をご確認ください。長い原稿は段階式で章ごとに作業してください。WordPressで公開する前にCocoonのブロック認識・リンク・広告コードを必ず確認してください。
